# Hoja de vida móvil - Danna Michelle Campos Samacá

Aplicación Expo/React Native con navegación inferior para presentar una hoja de vida.

## Ejecutar

1. Instala Node.js LTS.
2. Abre una terminal en esta carpeta y ejecuta `npm install`.
3. Ejecuta `npm start` y abre el proyecto con Expo Go o un emulador.

## Estructura

- `src/app/index.tsx`: datos personales y acciones de contacto.
- `src/app/estudios.tsx`: formación y certificaciones.
- `src/app/experiencia.tsx`: experiencia laboral.
- `src/app/hobbies.tsx`: intereses profesionales.
- `src/components`: botones y tarjetas reutilizables.

Los botones de contacto muestran una confirmación porque no se suministraron correo, teléfono ni perfil profesional. Sustituye las acciones en `src/app/index.tsx` cuando tengas esos datos.
